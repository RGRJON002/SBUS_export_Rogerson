# SBUS_export_Rogerson

MATLAB scripts for sampling Eulerian biogeochemical tracer fields from CROCO along offline Lagrangian particle trajectories generated using ROFF. These scripts were developed for the manuscript:

> **Carbon transport across the Cape Point Jet in the Southern Benguela Upwelling System**

The workflow combines Eulerian tracer fields with Lagrangian particle trajectories to investigate the evolution of coastal-origin water masses and their associated biogeochemical properties during offshore and along-shelf transport.

---

## Requirements

The scripts make use of the **CROCO_TOOLS** MATLAB toolbox.

- Penven et al. (2008)
- https://www.croco-ocean.org/download/

---

# Repository Structure

## 1. Eulerian Field Extraction

These scripts extract tracer or flux fields from CROCO NetCDF output and save them as MATLAB (`.mat`) files for subsequent Lagrangian sampling.

```
NPZD_get_tracer_slice.m
NPZD_get_flux_slice_V2.m
```

---

## 2. Lagrangian Sampling

These scripts sample the extracted Eulerian fields along backward Lagrangian trajectories generated by **ROFF**.

```
TRACK_PARTICLE.m
AGE_TRACER.m
sample_croco.m
age_statistics.m
mask_by_age.m
FU3D.m
FUtime.m
Fto3D.m
```

---

# Workflow

The recommended workflow is:

### Step 1 — Extract Eulerian Fields

Run either

```
NPZD_get_tracer_slice.m
```

to extract tracer fields (e.g. chlorophyll, nitrate, detritus), or

```
NPZD_get_flux_slice_V2.m
```

to extract fluxes across a specified depth interface.

These scripts produce a series of `.mat` files containing the required Eulerian variables.

---

### Step 2 — Sample Along Lagrangian Trajectories

After generating the Eulerian datasets, run

```
TRACK_PARTICLE.m
```

This is the main driver script and performs the following tasks:

- reads ROFF particle trajectories;
- samples the Eulerian fields at each particle position;
- computes particle age and associated statistics;
- stores all sampled variables in a structured MATLAB output file.

The resulting `.mat` file contains all sampled tracer fields and statistics required for further analysis and figure generation.

---

# Output

The sampled output includes age-conditioned statistics such as

- mean
- standard deviation
- median
- number of particles

for each sampled tracer (e.g. chlorophyll, nitrate, particulate organic carbon, remineralisation rate, etc.), making the workflow suitable for analysing the evolution of biogeochemical properties as a function of Lagrangian water age.

---

# Generality

Although developed for the Southern Benguela Upwelling System (SBUS), the scripts are largely generic and should be readily adaptable to other **CROCO** or **ROMS** model configurations with only minor modifications to variable names and directory structures.
